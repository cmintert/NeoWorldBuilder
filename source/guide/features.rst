Features
========

Core Concepts
-------------

NeoWorldBuilder organizes creative ideas around four fundamental concepts:

* **Names**: Unique identifiers for every element
* **Descriptions**: Rich textual content with formatting
* **Labels**: Categorical classification (Characters, Locations, Events, etc.)
* **Relations**: Meaningful connections between elements

Graph Database
--------------

Neo4j Integration
~~~~~~~~~~~~~~~~~

NeoWorldBuilder uses Neo4j graph database for efficient relationship management:

* Bidirectional relationship traversal
* Multi-project support with project isolation
* Automatic metadata tracking (created, modified, author)
* Stump node creation for incomplete references

Rich Text Editor
-----------------

The description editor supports:

* Markdown-style formatting
* Internal links to other nodes (hover to preview)
* Undo/redo functionality
* Export to various formats

AI Integration
--------------

LLM-Powered Features
~~~~~~~~~~~~~~~~~~~~

* Content generation and enhancement
* Smart suggestions based on context
* Autocomplete for node names
* Template-based content creation

Map Component
-------------

Interactive worldbuilding maps with:

* **Pins**: Mark locations on maps
* **Lines**: Draw roads, rivers, borders
* **Branching Lines**: Create complex route networks
* **Polygons**: Define regions and territories
* **Snapping**: Align features precisely
* **Edit Mode**: Modify existing map features

Calendar System
---------------

Create custom calendar systems with:

* Configurable months and days
* Season definitions
* Special events and holidays
* Timeline integration

Timeline
--------

Visualize events chronologically:

* Automatic date parsing
* Multiple date format support
* Event filtering by type
* Interactive timeline visualization

Fast Inject System
------------------

Quickly create complex entities from templates:

* Pre-configured templates (characters, locations, items)
* Customizable property sets
* Batch creation support
* Template sharing

Search and Analysis
-------------------

Powerful search capabilities:

* Full-text search across all nodes
* Label-based filtering
* Relationship path queries
* Debounced search for performance

Export Capabilities
-------------------

Export your worldbuilding content:

* Markdown export
* HTML export
* JSON data export
* Relationship graph visualization
